# Pau Morilla Portfolio

A personal web developer portfolio built to showcase my skills, projects, and experience as a Web Application Development (DAW) student.  
The portfolio is designed to be **clean, interactive, and fully responsive**, highlighting my best work and personal style.

---

## 🌟 What this portfolio includes

This portfolio is structured to give a clear overview of my abilities and projects:

1. **Header / Navigation** – Clean menu to navigate between sections.  
2. **Intro / Banner** – Engaging hero section introducing me, with call-to-action buttons.  
3. **Skills Section** – Visual progress bars for main skills (HTML, CSS, JavaScript) and extra skills tags.  
4. **Featured Project** – My best project highlighted with image, description, technologies, and status.  
5. **Other Projects** – Smaller projects overview (optional).  
6. **About Me Section** – Personal info, hobbies, and photo.  
7. **Contact Section** – Easy way to reach me via email or LinkedIn.  
8. **Footer** – Simple footer with my info and links.

**Design Highlights:**   
- Hover effects and smooth transitions  
- Clear visual hierarchy with typography and colors
